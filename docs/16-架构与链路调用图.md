## 3. 交互模式提示的链路调用图（一次完整 run）

```mermaid
sequenceDiagram
    autonumber
    participant U as 用户
    participant T as TUI (InteractiveMode)
    participant S as AgentSession
    participant A as Agent (pi-agent-core)
    participant L as agent-loop
    participant M as pi-ai Models
    participant P as Provider (厂商 API)

    U->>T: 输入 prompt
    T->>S: session.prompt(text, {streamingBehavior})
    S->>S: 扩展命令/input 拦截/skill+模板展开
    Note over S: streaming 中 → steer()/followUp() 入队列<br/>空闲 → 模型/认证预检 + 前置 compaction 检查
    S->>A: agent.prompt(messages)
    A->>L: runAgentLoop(prompts, ctx, config, emit, signal)
    L-->>S: agent_start / turn_start / 用户消息 message_start/end
    L->>L: streamAssistantResponse<br/>(transformContext → convertToLlm → getApiKey)
    L->>M: streamFn(model, llmContext, options)
    M->>M: applyAuth（凭据/headers/baseUrl）
    M->>P: provider.streamSimple → 流式响应
    P-->>M: AssistantMessageEvent 流
    M-->>L: 事件流（text/thinking/toolcall 增量）
    L-->>S: message_start / message_update* / message_end
    S-->>T: handleEvent → AssistantMessageComponent 增量渲染
    L->>L: executeToolCalls（顺序/并行）
    L-->>S: tool_execution_start / update / end
    S-->>T: ToolExecutionComponent 面板更新
    L-->>S: turn_end(message, toolResults)
    S->>S: turn_end → flush 待定自定义消息
    L-->>S: agent_end(messages)
    S->>S: _handlePostAgentRun：可重试→auto-retry<br/>溢出/截断→compaction；否则查队列
    alt 需要续跑
        S->>A: agent.continue()
    end
    S-->>T: agent_settled（会话真正空闲）
```

## 5. run 收尾决策链路（_handlePostAgentRun）

```mermaid
flowchart TD
    END["agent_end(messages)"] --> P["_handlePostAgentRun<br/>(agent-session.ts 1100)"]
    P --> N{"最后 assistant 消息<br/>可重试？"}
    N -- "是(瞬时错误)" --> R["_prepareRetry<br/>指数退避 + abortable sleep<br/>移除坏消息(保留历史)"]
    R --> C1{"agent.continue()"}
    N -- "否" --> C{"检查 compaction<br/>_checkCompaction"}
    C --> O{"overflow 且<br/>stopReason≠stop？"}
    O -- "是" --> OC["_runAutoCompaction(overflow, willRetry=true)<br/>_overflowRecoveryAttempted 防死循环"]
    OC --> C1
    O -- "响应完整但超窗" --> OT["_runAutoCompaction(overflow, false)"]
    OT --> C1
    C --> TH{"shouldCompact<br/>(threshold)？"}
    TH -- "是" --> TC["_runAutoCompaction(threshold, false)"]
    TC --> C1
    TH -- "否" --> Q{"agent.hasQueuedMessages()？"}
    Q -- "是" --> C1
    Q -- "否" --> SET["_emitAgentSettled → 空闲"]
    C1["agent.continue()<br/>(重试/压缩后继续被截断的 turn)"] --> P
```

## 6. 远程会话链路（pi-client ↔ pi-server）

```mermaid
sequenceDiagram
    autonumber
    participant C as PiClient
    participant T as ByteTransport (WebSocket/Unix)
    participant S as PiServer
    participant LM as LiveSessionManager
    participant RT as PiSessionRuntime（会话运行时，如 AgentSession）

    C->>T: connect() → transportFactory 完成认证
    T->>S: accept(connection) → awaitingHello
    C->>S: hello(version)
    S->>C: hello(connectionId, ServerSnapshot) → ready
    C->>C: acquireSession → SessionLease(exclusive/shared)
    C->>S: attach(sessionId)
    S->>LM: executeCommand(attach)
    LM->>RT: service.openSession(sessionId)
    C->>S: prompt(sessionId, text)
    S->>LM: executeCommand(prompt)
    LM->>RT: runtime.prompt({text})
    RT-->>S: 事件: session_progress（增量，UI 提示）
    RT-->>S: 事件: session_snapshot（权威状态）
    S-->>C: event(progress/snapshot)
    C->>C: 更新 ClientState（快照权威，progress 不合并）
    C->>S: detach(sessionId)
    S->>LM: 释放附着
    C->>C: 释放租约；最后一个租约释放后发 detach
```

## 7. 数据流一图流（用户输入 → 持久化）

```mermaid
flowchart LR
    IN["用户输入"] --> PRE["prompt 预处理<br/>扩展命令/技能/模板/认证预检"]
    PRE --> RUN["Agent run<br/>(prompt + N 次 continue)"]
    RUN --> EVT["AgentEvent 流"]
    EVT --> PERSIST["message_end → SessionManager<br/>写入会话 JSONL"]
    EVT --> UI["TUI 增量渲染"]
    EVT --> EXT["扩展事件"]
    EVT --> POST["_handlePostAgentRun<br/>重试/compaction/队列"]
    POST --> RUN
    PERSIST --> RECOVER["恢复：buildSessionContext()<br/>重建 agent.state.messages"]
```
